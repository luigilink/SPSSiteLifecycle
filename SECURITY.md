# Security Policy

## Supported Versions

Security fixes are applied to the latest release only.

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | :white_check_mark: |

## Reporting a Vulnerability

SPSSiteLifecycle can **delete SharePoint Online sites and Microsoft 365 groups** with the privileges of the administrator who runs it. We take vulnerabilities seriously.

**Please do not open a public GitHub issue for security vulnerabilities.**

Use the **GitHub Security Advisories** form (preferred): open the repository's **Security** tab and choose **Report a vulnerability**.

When reporting, please include:

- a description of the issue and its impact;
- steps to reproduce;
- affected version(s) and environment (PowerShell and PnP.PowerShell versions).

Do not attach real tenant data (tenant names, site URLs, owner names, usage reports, logs): replace it with made-up values.

We will acknowledge the report, investigate, and coordinate a fix and disclosure timeline with you.
